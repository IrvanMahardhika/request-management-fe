# Request Management FE

Vue 3 + Vite frontend for the operational request desk.

## Setup

```sh
npm install
npm run dev
```

Dev server proxies API calls to `http://localhost:3001`.

Open the printed Local URL (typically `http://localhost:5173`).

## Seeded logins

Use accounts from the API seed (password `Password123!`), e.g. `staff1@example.com`, `tm.east@example.com`, `admin@example.com`.
